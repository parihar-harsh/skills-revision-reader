Q3 What is the difference between var, let, and const?
ANSWER
var is function-scoped and can be redeclared. let is block-scoped and can be reassigned. const is block-scoped and cannot be reassigned.
COMPARISON
Feature                  | var                 | let                  | const
Scope                    | Function            | Block                | Block
Reassignment             | Allowed             | Allowed              | Not allowed
Same-scope redeclaration | Allowed             | Not allowed          | Not allowed
Before declaration       | undefined           | ReferenceError       | ReferenceError
Initializer required     | No                  | No                   | Yes
EXAMPLE 1 - SCOPE
function checkScope() {
  if (true) {
    var functionScoped = 1;
    let blockScoped = 2;
    const alsoBlockScoped = 3;
  }

  console.log(functionScoped);
  console.log(blockScoped);
}
OUTPUT
1
ReferenceError: blockScoped is not defined
EXAMPLE 2 - REASSIGNMENT
var first = 1;
first = 2;                 // Valid

let second = 1;
second = 2;                // Valid

const third = 1;
third = 2;                 // TypeError
RESULT
first stores 2
second stores 2
TypeError: Assignment to constant variable
EXAMPLE 3 - REDECLARATION
Run each case below as a separate script because either SyntaxError prevents that entire script from executing.

var score = 20;            // Valid
RESULT
score stores 20

let total = 10;
let total = 20;            // SyntaxError in the same scope

const limit = 10;
const limit = 20;          // SyntaxError in the same scope
RESULT FOR EACH SEPARATE CASE
SyntaxError: Identifier has already been declared

console.log(newValue);     // ReferenceError: temporal dead zone

user = { name: "Amit" };   // TypeError: binding cannot change
RESULT

QUICK RULE
Use const by default, use let when reassignment is required, and avoid var in modern JavaScript unless function scope is intentional.

Q36 What is the event loop?
ANSWER
The event loop checks whether the call stack is empty and then runs ready callbacks. Promise microtasks are handled before the next timer or I/O task.
EXAMPLE
A timer expires outside JavaScript execution, its callback becomes eligible, and the event loop runs it only after current synchronous code and required microtasks finish.

Q37 What is the call stack?
ANSWER
The call stack keeps track of currently running function calls. The newest function call finishes first.
EXAMPLE

Q38 What happens if the call stack is blocked?
ANSWER

Q82 What is normalization, and what are 1NF, 2NF, and 3NF?
ANSWER

HTTP caching lets a browser or proxy reuse a fresh response or ask whether an older response has changed before downloading it again.
EXAMPLE
Browser caches app.css with an ETag; next request sends If-None-Match -> unchanged server returns 304 and the browser reuses cached bytes.

Q265 What is WebSocket?
ANSWER
WebSocket creates a persistent two-way connection where both client and server can send text or binary messages at any time.
EXAMPLE
A collaborative editor sends cursor changes from client to server and receives other users' edits over the same WebSocket connection.

Q266 What is request-response cycle?
ANSWER
In the request-response cycle, the client sends an HTTP request, server middleware and business logic process it, and the server returns an HTTP response.
EXAMPLE
POST /login reaches parsing and validation middleware, the login handler checks the credentials, and the server returns a status code with a response body.
