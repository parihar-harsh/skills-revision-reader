Q2 What is the difference between var, let, and const?High frequency
ANSWER
var is function-scoped and can be redeclared. let is block-scoped and can be reassigned. const is block-scoped and cannot be reassigned.
COMPARISON
Feature                  | var                 | let                  | const
Scope                    | Function            | Block                | Block
Reassignment             | Allowed             | Allowed              | Not allowed
Same-scope redeclaration | Allowed             | Not allowed          | Not allowed
Before declaration       | undefined           | ReferenceError       | ReferenceError
Initializer required     | No                  | No                   | Yes
EXAMPLE 1 - SCOPE
function checkScope() {
  if (true) {
    var functionScoped = 1;
    let blockScoped = 2;
    const alsoBlockScoped = 3;
  }

  console.log(functionScoped);
  console.log(blockScoped);
}
OUTPUT
1
ReferenceError: blockScoped is not defined
EXAMPLE 2 - REASSIGNMENT
var first = 1;
first = 2;                 // Valid

let second = 1;
second = 2;                // Valid

const third = 1;
third = 2;                 // TypeError
RESULT
first stores 2
second stores 2
TypeError: Assignment to constant variable
EXAMPLE 3 - REDECLARATION
Run each case below as a separate script because either SyntaxError prevents that entire script from executing.

RESULT
score stores 20

let total = 10;
let total = 20;            // SyntaxError in the same scope

const limit = 10;
const limit = 20;          // SyntaxError in the same scope
RESULT FOR EACH SEPARATE CASE
SyntaxError: Identifier has already been declared

console.log(newValue);     // ReferenceError: temporal dead zone

QUICK RULE
Use const by default, use let when reassignment is required, and avoid var in modern JavaScript unless function scope is intentional.
